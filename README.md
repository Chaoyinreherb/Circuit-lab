# Circuit Lab - インタラクティブ回路シミュレータ
__with AI__

ブラウザ上でリアルタイムに動作する、視覚的・実験的な回路シミュレータアプリです。
SPICE系のバッチ処理ではなく、リアルタイムの修正節点解析法（MNA）＋Newton-Raphson法＋台形積分によるシミュレーションエンジンを搭載し、実験ベンチのようにオシロスコープや電流計の端子（プローブケーブル）を回路上の好きな場所に接続して測定できます。

---

## 🌟 主な特徴

1. **実機感覚のプローブ測定システム**:
   - **2-CH オシロスコープ**: CH1（赤）、CH2（青）、GND（黒）のプローブリード線を回路の各端子やノードへドラッグ＆ドロップして接続。リアルなベジェ曲線のケーブルが接続ポイントへ結ばれ、どこを測定しているかが直感的に把握できます。
   - **デジタルマルチメーター (DMM) / 電流計**: (+)（赤）、(-)（黒）のテストピンおよび、回路を切断せずに素子を挟むだけで測定できる「電流クランププローブ」を装備。DC V, AC V(rms), DC A, AC A, 抵抗(Ω)を計測可能。
2. **リアルタイム回路シミュレーション (MNA)**:
   - 電圧に応じた色分け（緑: GND/0V、赤: 正電圧、青: 負電圧）
   - 電荷（電流）のアニメーション（導線内を流れる動く黄色い電荷粒子）
3. **初期対応素子**:
   - **R**: 抵抗
   - **L**: コイル（インダクタ）
   - **C**: コンデンサ
   - **ダイオード**: 順方向電圧降下・非線形特性
   - **トランジスタ (BJT)**: NPN (2SC1815等)、PNP (2SA1015等)
   - **電源・制御**: 直流電源 (DC)、交流信号源 (AC 正弦波/方形波/三角波)、GND (0V基準)、SPSTスイッチ、直列電流計
4. **JSONによる拡張性**:
   - ユーザー側でJSONを記述・インポートするだけで、新しい素子（LED、ツェナーダイオード、オペアンプ、カスタム複合モジュールなど）をパレットに即座に追加可能。
5. **充実のプリセット回路**:
   - RCローパスフィルタ（時定数とAC応答）
   - 半波整流 ＆ 平滑回路（ダイオード整流と平滑化コンデンサ）
   - RLC 直列共振回路（減衰振動）
   - トランジスタ増幅回路（NPNエミッタ接地小信号増幅）

## 🚀 起動方法

Node.jsが必要です。

```bash
npm run dev
```

ブラウザで `http://localhost:5173` を開くと起動します。

---

## 🎮 基本操作方法

- **素子の配置**: 上部ツールバーの素子ボタンをクリックすると、作業スペースに素子が追加されます。
- **素子の移動**: 素子をドラッグして移動。
- **素子の回転**: 素子をクリックして選択し、キーボードの `R` キーを押す。
- **素子の削除**: 素子をクリックして選択し、キーボードの `Delete` または `Backspace` キーを押す。
- **配線 (ワイヤー接続)**: 素子の水色の端子ピンをクリック＆ドラッグして、別の端子ピンへ繋ぐ。
- **スイッチの切り替え**: 回路上のスイッチをクリックすると、開 (OFF) / 閉 (ON) がトグルします。
- **パラメータ変更**: 素子をクリックすると、右下パネルで抵抗値、容量、電圧、周波数などをリアルタイムに変更できます。
- **測定プローブの接続**:
  - オシロスコープの CH1 (赤), CH2 (青), GND (黒) のプローブ先端をドラッグし、測定したい端子ピンにドロップします。
  - 電流クランププローブ（黄）は素子本体にドロップすると、その素子に流れる電流をDMMで測定します。

## 🧩 JSONによるカスタム素子の追加方法

ツールバーの **「+ JSON素子追加」** ボタンをクリックすると、JSON定義エディタが開きます。

### 1. パラメータ型カスタム素子の例 (青色LED)

```json
{
  "kind": "parametric",
  "typeId": "led_blue_custom",
  "name": "Custom Blue LED",
  "category": "Semiconductors",
  "description": "3.2V forward drop blue LED",
  "baseType": "led",
  "color": "#3b82f6",
  "pins": [
    { "id": "anode", "name": "A (+)", "x": -20, "y": 0, "direction": "left" },
    { "id": "cathode", "name": "K (-)", "x": 20, "y": 0, "direction": "right" }
  ],
  "params": {
    "Vf": 3.2,
    "Is": 1e-16,
    "color": "#3b82f6"
  }
}
```

### 2. サブサーキット型カスタム素子の例 (オペアンプ LM358)

```json
{
  "kind": "subcircuit",
  "typeId": "opamp_custom",
  "name": "Custom Op-Amp",
  "category": "IC / Amplifiers",
  "description": "Ideal Op-Amp differential model",
  "width": 60,
  "height": 50,
  "symbolShape": "triangle",
  "pins": [
    { "id": "in_pos", "name": "+", "x": -30, "y": -15, "direction": "left" },
    { "id": "in_neg", "name": "-", "x": -30, "y": 15, "direction": "left" },
    { "id": "out", "name": "OUT", "x": 30, "y": 0, "direction": "right" }
  ],
  "internalElements": [
    {
      "id": "rin",
      "type": "resistor",
      "pins": { "pin1": "in_pos", "pin2": "in_neg" },
      "params": { "value": 1e7 }
    },
    {
      "id": "vcvs",
      "type": "vcvs",
      "pins": { "out_pos": "out", "out_neg": "ground", "ctrl_pos": "in_pos", "ctrl_neg": "in_neg" },
      "params": { "gain": 100000, "rout": 50 }
    }
  ]
}
```

登録した素子はブラウザのローカルストレージにも保持され、いつでもツールバーの「拡張素子」プルダウンから回路に呼び出せます。
